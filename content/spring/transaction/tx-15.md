**모범 답변 (30~60초)**
프록시 방식에서는 외부에서 프록시를 통해 들어오는 호출만 인터셉트됩니다. 같은 객체 안에서 `this.method()`로 부르면 프록시를 거치지 않고 실제 객체의 메서드를 바로 부르기 때문에 `@Transactional`이 적용되지 않습니다. 데모의 `selfInvocation`이 이걸 보여줍니다. 트랜잭션 없는 메서드가 `this.innerTransactionalFail`을 호출하고 거기서 예외가 나는데, 테스트에서 확인하면 롤백되지 않고 행이 1건 남아 있습니다. 해결책은 메서드를 별도 빈으로 분리하거나, `TransactionTemplate`을 쓰거나, AspectJ 모드로 전환하는 것입니다.

```java
public void selfInvocation(String email) {
    this.innerTransactionalFail(email);   // 프록시를 안 거침 -> 롤백 안 됨
}
@Transactional
public void innerTransactionalFail(String email) { ... throw ... }
```

(공식 문서) 프록시 모드에서는 자기 호출에 트랜잭션이 적용되지 않으며, 필요하면 `aspectj` 모드를 쓰라고 한다. 프록시가 완전히 초기화되어야 하므로 `@PostConstruct` 같은 초기화 코드에서 이 기능에 의존하지 말라는 주의도 있다.
(보충) 자기 자신을 주입받는 방식은 일반적으로 쓰이는 우회책이지만 이번 문서에서 확인한 내용은 아니다.
