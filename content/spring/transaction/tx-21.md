**모범 답변 (30~60초)**
`@Transactional`의 `value`(별칭 `transactionManager`)에 빈 이름이나 qualifier를 지정해서 선택합니다. 지정하지 않으면 기본 트랜잭션 매니저가 쓰입니다. 예를 들어 주문 DB와 계정 DB를 분리했다면 `@Transactional("order")`처럼 명시하고, 반복이 많으면 이 설정을 담은 커스텀 합성 어노테이션을 만들 수 있습니다. 서로 다른 DB에 걸친 일관성은 이 방식으로 자동 보장되지 않습니다.

(공식 문서) annotations 페이지의 "Multiple Transaction Managers" 절은 `value` 또는 `transactionManager`에 빈 이름이나 qualifier 값을 지정해 선택한다고 설명하고, `@Transactional("order")` 같은 예시를 든다. 6.2부터는 타입 수준 빈 qualifier도 함께 고려되며 커스텀 합성 어노테이션도 같은 페이지에 있다. 같은 페이지 표는 XML 설정에서 트랜잭션 매니저 이름이 `transactionManager`가 아니면 지정해야 한다고 한다.
(보충) 자바 설정에서 아무것도 지정하지 않았을 때 어떤 매니저가 고르는지의 정확한 규칙은 이번에 확인하지 못했다. 마지막 문장(서로 다른 DB에 걸친 일관성은 자동 보장되지 않는다)도 문서가 직접 설명한 것이 아니다.
