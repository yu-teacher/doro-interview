**모범 답변 (30~60초)**
Java 25 튜닝 가이드는 Serial, Parallel, G1, ZGC 네 가지를 설명하고, 여기에 Shenandoah는 25에서 세대 모드가 제품 기능이 됐습니다. 컬렉터를 지정하지 않으면 JVM이 하드웨어와 OS 구성에 맞춰 고르는데 대부분 G1이 기본입니다. 가이드가 권하는 출발점은 이렇습니다. 데이터가 작거나(약 100MB) 단일 프로세서면 Serial, 최고 처리량이 우선이고 1초 이상 정지도 괜찮으면 Parallel, 응답 시간이 더 중요하면 G1, 응답 시간의 우선순위가 높으면 ZGC입니다. 출발점일 뿐이라 힙 크기와 라이브 데이터 양에 따라 달라집니다.

| Java 버전 | GC 관련 변화 | 근거 |
|---|---|---|
| 9 이전 | 서버 구성의 기본이 Parallel | JEP 248 |
| 9 | G1이 서버 구성의 기본(CPU 1개이거나 물리 메모리 1792MB 미만이면 Serial을 고르도록 조정), CMS deprecate | JEP 248, JEP 523, JEP 291 |
| 14 | CMS 제거 | JEP 363 |
| 15 | ZGC가 실험에서 제품 기능으로 | JEP 377(11에서 실험 도입, JEP 333) |
| 21 | 세대별 ZGC 추가(옵션) | JEP 439 |
| 23 | ZGC 기본 모드가 세대별 | JEP 474 |
| 24 | ZGC 비세대 모드 제거, Shenandoah 세대 모드 실험 도입 | JEP 490, JEP 404 |
| 25 | Shenandoah 세대 모드가 제품 기능(기본은 단일 세대 유지) | JEP 521 |
| 27 | 모든 환경에서 G1이 기본(25 이후, 참고) | JEP 523 |

(공식 문서) 선택 기준은 튜닝 가이드 5장(Available Collectors)에 근거한다. 이 장의 서두는 컬렉터가 세 가지라고 적지만 절은 Serial, Parallel, G1, Z 네 가지다. 이 장은 응답 시간이 높은 우선순위면 ZGC를 고르라고 하고, Serial은 단일 스레드, Parallel은 다중 스레드 처리량 컬렉터이며 G1은 대부분의 구성에서 기본이라고 설명한다. `java` 도구 문서는 G1이 약 6GB 이상의 큰 힙에서 안정적이고 예측 가능한 정지 시간(0.5초 미만)이 필요한 애플리케이션에 권장된다고 하고, ZGC의 정지 시간이 힙 크기와 무관하며 힙을 8MB에서 16TB까지 지원한다고 한다.
(실험 확인) Java 25(Corretto 25.0.3, 15코어 macOS)에서 `-Xlog:gc -version`으로 확인했다. 옵션 없이는 `Using G1`, `-XX:+UseSerialGC`는 `Using Serial`, `-XX:+UseParallelGC`는 `Using Parallel`, `-XX:+UseZGC`는 ZGC로 시작했다. `-XX:+UseConcMarkSweepGC`는 `Unrecognized VM option`으로 실패했고, `-XX:+UseZGC -XX:-ZGenerational`은 "Ignoring option ZGenerational; support was removed in 24.0" 경고를 냈다.
(공식 문서) 가이드는 Serial이 특정 하드웨어·OS 구성에서 기본으로 선택될 수 있다고만 하고 조건은 적지 않는다. JEP 523(Release 27)은 JDK 9에서 G1을 기본으로 하면서 CPU 1개이거나 물리 메모리가 1792MB 미만인 환경에서는 Serial을 고르도록 조정했고, 27부터 모든 환경에서 G1을 고른다고 설명한다. 그래서 25 기준 기본 GC가 G1이라는 말에는 "대부분의 구성에서"라는 단서가 붙는다.
(실험 확인) `-XX:ActiveProcessorCount=1`을 주면 `Using Serial`, `=2`면 `Using G1`이었다. `-XX:+UseShenandoahGC`는 `Using Shenandoah`로 시작했다(Corretto 25.0.3 기준).
(실험 확인) CPU 15개로 보이는 컨테이너에서 `-XX:+PrintFlagsFinal`로 기본 GC를 보면 Corretto 8(1.8.0_512)은 `UseParallelGC := true`(G1 false), Corretto 11.0.33과 17.0.21은 `UseG1GC = true`(ergonomic 선택)였다(9에서 G1 기본이라는 설명과 일치, 9 자체는 확인하지 못했다). 다만 11과 17에 `-XX:ActiveProcessorCount=1`을 주면 `UseSerialGC = true`였고, 메모리를 1GB로 제한한 컨테이너의 11도 Serial을 골라, G1 기본은 서버급 머신으로 판정될 때의 얘기다.
