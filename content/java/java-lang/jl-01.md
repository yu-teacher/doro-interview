**모범 답변 (30~60초)**
자바의 타입은 기본 타입과 참조 타입 두 종류입니다. 기본 타입은 boolean과 byte, short, char, int, long, float, double 여덟 가지이고 변수에 값 자체가 들어갑니다. 참조 타입은 클래스, 인터페이스, 배열이며 변수에는 객체를 가리키는 참조가 들어갑니다. 그래서 참조 변수에는 아무것도 가리키지 않는 null을 넣을 수 있지만 기본 타입은 그럴 수 없습니다. 제네릭의 타입 인자도 참조 타입만 올 수 있어서 List<int>는 안 되고, 이럴 때 기본 타입에 대응하는 Integer 같은 래퍼 클래스를 씁니다.

```java
List<int> l;   // javac 25: error: unexpected type, required: reference
```

(공식 문서) JLS 4.1은 타입이 기본 타입과 참조 타입 두 종류이고, 기본 타입은 boolean과 숫자 타입(byte, short, char, int, long, float, double), 참조 타입은 클래스·인터페이스·배열 타입이라고 정의한다. 4.1은 null 참조를 모든 참조 타입에 대입하거나 캐스트할 수 있다고 하며 null 타입은 이름이 없는 별도의 타입이라고 한다. 4.5.1은 타입 인자가 참조 타입이거나 와일드카드라고 한다.
(실험 확인) 위 코드를 javac 25(Corretto 25.0.3)로 컴파일하면 `unexpected type`, `required: reference` 오류가 났다. `int x = null;`도 `incompatible types: <null> cannot be converted to int` 오류였다.
