**모범 답변 (30~60초)**
자바는 항상 값에 의한 전달입니다. 메서드를 호출하면 인자 표현식의 값이 새로 만들어진 매개변수 변수에 복사되고, 기본 타입이면 숫자 값이, 참조 타입이면 객체를 가리키는 참조값이 복사됩니다. 그래서 메서드 안에서 매개변수에 새 객체를 대입해도 호출한 쪽 변수는 바뀌지 않습니다. 다만 복사된 참조도 같은 객체를 가리키므로, 그 객체의 필드를 바꾸면 호출한 쪽에서도 변경이 보입니다. 이 모습이 참조로 전달되는 것처럼 보여서 생기는 흔한 오해입니다.

```java
static void mut(P p)    { p.v = 99; }          // 같은 객체의 필드를 바꿈
static void rebind(P p) { p = new P(); p.v = 7; } // 지역 매개변수만 새 객체를 가리킴
static void inc(int x)  { x++; }
// P p = new P(); p.v = 1; 후 mut(p) -> 99, rebind(p) -> 여전히 99, int i=1; inc(i) -> 여전히 1
```

(공식 문서) JLS 8.4.1은 메서드나 생성자가 호출될 때 실제 인자 표현식의 값이 새로 만들어진 매개변수 변수를 초기화한다고 하고, 15.12.4.2는 인자 표현식을 평가한 결과가 인자 값(argument value)이라고 하고, 15.12.4.5는 인자 값이 새로 만들어진 매개변수 변수에 대입된다고 한다. JLS 4장 서두는 참조 타입의 값이 객체에 대한 참조라고 한다.
(실험 확인) 위 세 메서드를 실행한 출력은 `mut 99`, `rebind 99`, `inc 1`이었다.
(보충) "값에 의한 전달"이라는 용어 자체는 JLS 4·5·8·15장에서 찾지 못했다(`by value`, `by reference`를 검색). 자바는 항상 값 전달이라는 결론은 위 규정에서 따라 나오는 일반적인 요약이다.
