**모범 답변 (30~60초)**
map은 원소 하나를 원소 하나로 바꾸는 1:1 변환이고, flatMap은 원소 하나를 스트림으로 바꾼 뒤 그 스트림들의 내용을 하나의 스트림으로 이어 붙이는 1:N 변환입니다. 그래서 flatMap에 넘기는 함수는 Stream을 돌려줘야 하고, 주문 목록에서 주문 항목 전체를 뽑거나 줄 단위 텍스트를 단어 스트림으로 펼치는 데 씁니다. List의 List에 map(List::size)를 쓰면 크기 목록이 되고, flatMap(List::stream)을 쓰면 안쪽 원소가 평탄화됩니다. 결과 원소가 적을 때는 Java 16의 mapMulti가 스트림 생성 비용을 줄이는 대안입니다.

```java
Stream.of(List.of(1,2), List.of(3)).map(List::size).toList();       // [2, 1]
Stream.of(List.of(1,2), List.of(3)).flatMap(List::stream).toList(); // [1, 2, 3]
Stream.of(1,2).<Integer>mapMulti((x, c) -> { c.accept(x); c.accept(x*10); }).toList(); // [1, 10, 2, 20]
```

(공식 문서) Stream.flatMap 문서는 각 원소를 매핑된 스트림의 내용으로 치환하는 일대다 변환 후 평탄화하는 연산이며, 매핑된 각 스트림은 내용을 옮긴 뒤 닫히고 null 스트림은 빈 스트림으로 취급한다고 설명한다. 주문 항목과 줄 단위 단어 예시도 문서에 있다. mapMulti는 Since 16이며, 소수의 원소로 치환할 때 flatMap이 요구하는 스트림 인스턴스 생성 비용을 피할 수 있다고 API Note에 적혀 있다.
(실험 확인) 위 세 줄을 Java 25에서 실행해 주석의 결과를 확인했다. 매퍼가 null 스트림을 돌려주면 빈 결과(`[]`)였고, 매핑된 스트림은 flatMap 뒤 닫혀 다시 쓰면 IllegalStateException이었다.
