**모범 답변 (30~60초)**
세 알고리즘 모두 임의 입력에서는 O(n²)입니다. 버블 정렬은 인접한 쌍을 비교해 바꾸며 훑는 일을 교환이 없을 때까지 반복하므로 이미 정렬된 입력에서는 Θ(n)에 가깝습니다. 삽입 정렬은 다음 원소를 앞쪽의 정렬된 부분 안 제자리에 끼워 넣으며 시간이 원소 이동 때문에 O(n²)이라서, 이미 정렬된 입력에서는 이동이 없어 선형에 그칩니다. 선택 정렬은 남은 것 중 최솟값을 찾아 제자리로 보내며 실행 시간이 Θ(n²)이고 교환은 O(n)번입니다. 같은 O(n²)여도 입력 상태에 따라 실제 연산 수는 크게 달라집니다.

(공식 문서) DADS bubble sort 항목은 임의 데이터에서 O(n²)이고 거의 정렬된 입력에서는 Θ(n)에 가까워지며 swap이 없을 때까지 반복한다고 쓴다. insertion sort 항목은 시간이 이동 때문에 O(n²)이라 하고, selection sort 항목은 실행 시간 Θ(n²), swap 횟수 O(n)이라고 한다.
(실험 확인) n = 1000(Python 3.14로 직접 구현)에서 n(n-1)/2 = 499,500이다. 무작위 입력의 비교/이동 횟수는 버블 498,015/250,393, 삽입 251,387/250,393, 선택 499,500/991이었다. 이미 정렬된 입력에서는 버블과 삽입이 각각 999번 비교(이동 0)에 그쳤고 선택은 그대로 499,500번이었다. 역순 입력에서는 버블과 삽입 모두 499,500번 비교·이동이었고 선택은 교환 500번이었다.
(보충) 삽입 정렬이 이미 정렬된 입력에서 선형이 된다는 것은 DADS가 직접 서술하지 않으며(O(n²)와 이동 때문이라는 점만 있다) 위 실험(비교 999번, 이동 0)과 알고리즘 구조에서 따라 나오는 설명이다. 쓰기 비용이 큰 저장소에서는 교환이 적은 선택 정렬이 유리할 수 있다는 것은 위 교환 횟수에서 따라 나오는 일반적 추론이며 문서가 권하는 것은 아니다.
